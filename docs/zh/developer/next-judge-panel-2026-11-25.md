# Aventine 下一轮中英评测裁判配置

决策日期为 2026-11-25。本配置从下一轮新建中英固定锚点评测启用。

| 优先级 | 模型 | 接入方式 |
| --- | --- | --- |
| 主审 | GPT‑6.2 Sol（gpt-6.2-sol） | 直连 OpenAI API，使用 OpenAI 平台额度，以 medium 开始校准 |
| 副审 | DeepSeek V4.1 Flash 1017（deepseek/deepseek-v4.1-flash-20261017） | 固定 1017 快照和通过校准的路由 |
| 补裁 | Gemini 4 Hydrogen（gemini-4-hydrogen） | 固定通过校准的路由 |

每个案例首先由优先级最高的两位合格裁判独立投票。双审分歧或缺票时，才调用仍符合条件的第三位裁判。候选模型和锚点均触发同家族回避。GPT 场次由 DeepSeek 1017 和 Hydrogen 主审。少于两张一致有效票的案例保留未决。

正式运行前，用有人审答案的双向中英盲测核验裁判正确率、换序一致性、结构化输出通过率、耗时和每个有效裁决的成本。将模型快照、端点、推理强度和预算门禁写入运行清单，再为该配置建立独立评分版本。2026-11-25 已启动的评测使用其原先冻结的裁判配置。

## 换序审计与成本

新裁判组合先分中译英和英译中抽取 20% 的软偏好案例做换序审计。对同一批案例再做一组原顺序重跑，保持裁判模型、路由、提示词与推理配置一致，用来估计重复调用本身的波动。两位主审仍以相反顺序阅卷。按方向和实际裁判组合分别比较原序与换序的翻票率和第一位置的净偏向，单列缺票。只有两个方向都达到校准前登记的稳定条件，后续同配置的常规抽查才降到 10%。本轮只执行已经冻结的 20% 换序方案。

裁判成本优化以每个有效裁决的费用和裁判费／选手生成费比值为主，按方向及实际裁判组合记录覆盖率。分别记录校准、常规双审、补裁和换序费用，并区分 API 计费金额与额度抵扣后的实际支出。缺少成本凭据时单列未知项，避免低估费用。优先减少通过校准后可缩减的审计调用，以有效裁决覆盖率核验节省效果。
